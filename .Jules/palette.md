# 2024-03-24 - Accessibility and Loading State Enhancements
**Learning:** Several key icon-only buttons (like Settings in the Navbar and view toggles in Matches) were missing `aria-label`s, which makes navigation difficult for screen reader users. Also, while loading states existed, they were static. Adding a simple `animate-pulse` class along with `aria-live="polite"` makes the wait feel significantly more responsive without over-engineering the spinner. Furthermore, the empty state in the Matches view lacked an actionable CTA, leaving users without clear next steps.
**Action:** When creating icon-only buttons or interactive toggles, always include `aria-label` (and `aria-pressed` for toggles) by default. For empty states, ensure there is an immediate CTA (like "Update Profile") to guide the user rather than just displaying static informative text. Ensure loading text is marked with `aria-live` for screen readers.
