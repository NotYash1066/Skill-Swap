# Tech Stack

## Frontend
- **Framework:** React 18.2.0 (Vite-powered)
- **Language:** JavaScript (ESM)
- **Real-time Communication:** Socket.io-client
- **WebRTC:** PeerJS & Simple-Peer
- **State Management:** React Context API
- **Styling:** CSS (Modular approach)
- **Animation:** Framer Motion
- **Collaborative Canvas:** Fabric.js

## Backend
- **Environment:** Node.js
- **Framework:** Express 4.21.2
- **Language:** JavaScript (CommonJS)
- **Database:** MongoDB with Mongoose ODM
- **Real-time Engine:** Socket.io
- **In-memory Storage/Caching:** Redis
- **Security:** Helmet, Express Rate Limit
- **Authentication:** JSON Web Tokens (JWT) & BcryptJS

## Infrastructure & Tools
- **Version Control:** Git
- **Containerization:** Docker (Dockerfile & docker-compose.yml present)
- **Testing:** Jest & Supertest
- **Linting:** ESLint
- **Package Manager:** npm
